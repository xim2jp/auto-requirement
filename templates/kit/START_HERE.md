# はじめにお読みください

このフォルダには、**作りたいシステムの説明から、要件定義の書類一式を作る仕組み**が入っています。Claude Code に話しかけるだけで使えます。専門知識は要りません。

## 使い方（3 ステップ）

1. このフォルダで Claude Code を起動します

   ```
   claude
   ```

2. 作りたいシステムのことを、思いつくままに話しかけます（数行で大丈夫です）

   > 美容室の予約をスマホで受けられるようにしたい。今は電話と紙の台帳で受けていて、営業中に電話に出られないことが多い。スタッフは 3 人。

3. いくつか質問が来るので答えます。分からないものは「おまかせ」で大丈夫です

あとは、こちらで次の順に進めます。途中で、内容の確認と、決めていただきたいことを何度かお聞きします。

| 順番 | やること | あなたにお願いすること |
|------|---------|-------------------|
| 1 | お話から「依頼内容のまとめ（RFP）」を作る | 質問に答える、まとめを確認する |
| 2 | RFP をもとに、システムに求めることを整理する | 追加の質問に答える |
| 3 | 内容を点検し、書類にする | 書類の宛名・作成者名を決める |
| 4 | できあがった書類を確認して、お渡しする | 決めていただきたいことに答える |

## できあがる書類（`deliverables/` フォルダ）

| 書類 | 形式 | 内容 |
|------|------|------|
| 要件定義要求書（RFP） | Word | 何のために、何を作りたいかのまとめ |
| 要件定義書 | Word | システムに求めることを、作る人に誤解なく伝わる形で決めた正式な書類 |
| 付録文書（別紙 1〜7） | Word | やりたいことの一覧、操作の流れ、速さや安全性の条件、用語集、決めていただきたいことなど |
| 要件一覧 | Excel | すべての項目の一覧表（絞り込み・集計ができます） |
| 要件定義サマリー | PowerPoint | 決裁する方に説明するためのスライド |

## 資料があるとき

今使っている Excel・紙の帳票の写真・メモ、すでにある RFP（提案依頼書）などは、`docs/00-inputs/` フォルダに置いてから「資料を置きました」と伝えてください。なくても始められます。

## 進み具合を知りたいとき

「今どこまで進んでいる？」と聞いてください。

## 必要なもの

- Claude Code
- Python 3（書類を Word・Excel・PowerPoint にするときに使います。初回に必要な部品を自動で準備します）
